AI · Content operations

Media catalogue with an eligibility engine

Problem

Thousands of unlabelled files in cloud storage. The people choosing content could not tell what a file contained without opening it, could not tell whether it had already gone out, and had no idea that six files from the same shoot were the same look — so the same content shipped twice and customers noticed.

How I work

The habits that make the systems hold up

Anyone can ship a workflow. The reason this operation still runs unattended is a set of rules I apply to my own work — most of them learned the expensive way, and each one written down so it is never learned twice.

01Measure it; don’t assume it

Numbers get date-stamped and re-measured before they are quoted. When five documents disagreed on a workflow count, the fix was not to pick one — it was to define the single place the measurement lives and record when it was taken. Every claim on this page came from a measurement, not a memory.

02A success report is not evidence

“It ran” and “it worked” are different claims. Writes are verified by reading back through a path independent of the write. Deploys are verified inside the running container, not from the deploy script’s own output. Several things that reported success had done nothing at all.

03An alarm that never clears is not an alarm

A permanently-raised alert is a disabled one. Before hardening a check, I confirm its output channel still carries information — otherwise the work looks like progress and changes nothing. The fix is usually to scope the signal, not to grind through the noise it produced.

04Enforce at the choke point, not in a report

A rule that lives in a document is advice. The media eligibility engine only started working the day the picker read it — one join, and four separate consumers inherited the verdict. Put the check where the decision is actually made.

05Degrade loudly, never silently

Systems that fail quietly fail three times before anyone notices. Staleness is signalled from something that cannot be faked by a failed run, surfaced on the page it affects, and made non-dismissible. Restrictions are additive, so a stale check under-restricts — it can never permit more than the old behaviour.

06Gates before sends, humans on the trigger

Nothing customer-facing or people-facing auto-sends. Drafts are drafts. Quoted evidence is machine-verified against its source, output is schema-validated, and a person signs off. Automation removes the work, not the accountability.

07Write it down where the next person reads

Durable facts get promoted out of a live working file into permanent memory on a defined rule. Rejected paths are recorded alongside the chosen one, so nobody re-litigates a settled decision. Sixteen AI agents and every new hire read the same source of truth.

08Say plainly what is not done

Every status carries what landed, what is staged behind a gate, and what is still open — with the reason. A thing that is 2 of 5 steps built gets described as 2 of 5. Optimistic reporting is the most expensive habit in operations.
